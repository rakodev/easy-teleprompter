Reading Guide

Welcome to the Web Teleprompter!

This web-based teleprompter provides smooth auto-scrolling text perfect for video recording, presentations, or public speaking.

How to Use:

  1. Click "Edit Text" to write your own content, or "Load File" to import a text file
  2. Adjust the font size and speed to your preference
  3. Click Play or press SPACE to start scrolling
  4. Use keyboard shortcuts for hands-free control

Keyboard Shortcuts:

  • SPACE: Play/Pause
  • Arrow Keys: Navigate and adjust speed
  • R: Reset to beginning
  • F: Toggle fullscreen
  • M: Toggle mirror mode
  • +/-: Adjust font size
  • H: Show help
