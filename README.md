# Web Teleprompter

A professional web-based teleprompter that runs entirely in your browser.

## How to Run

1. **Open `index.html`** in any modern web browser
2. That's it! No installation required.

### Alternative: Using a Local Server
If you need file loading features, start a simple HTTP server:

```bash
# Python 3
python3 -m http.server 8000

# Node.js  
npx http-server

# PHP
php -S localhost:8000
```

Then visit `http://localhost:8000`

## How to Use

1. **Add Content**: Click "Edit Text" to write your script, or "Load File" to import a .txt file
2. **Adjust Settings**: Set font size and scroll speed to your preference
3. **Start Presenting**: Click Play or press SPACE to begin scrolling
4. **Control**: Use keyboard shortcuts for hands-free operation

## Keyboard Shortcuts

- **SPACE** - Play/Pause
- **←/→** - Rewind/Fast Forward  
- **↑/↓** - Adjust speed
- **R** - Reset to beginning
- **F** - Fullscreen mode
- **M** - Mirror mode (for cameras)
- **+/-** - Font size
- **H** - Show help
